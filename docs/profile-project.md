# Snow-Warrior07

## Featured project: Traction-aware warehouse rover

A fully virtual control-engineering project combining **linear PI/LQR**, **nonlinear tracking**, **traction supervision**, **ROS 2**, and an editable **KiCad 10 PCB**.

**[Try the interactive demo](https://snow-warrior07.github.io/traction-aware-amr/)** · [Explore the source](https://github.com/Snow-Warrior07/traction-aware-amr) · [Download the KiCad project](https://snow-warrior07.github.io/traction-aware-amr/downloads/traction-aware-amr-kicad.zip)

[![Actual KiCad render of the Pico carrier](https://raw.githubusercontent.com/Snow-Warrior07/traction-aware-amr/main/site/assets/carrier-isometric.png)](https://snow-warrior07.github.io/traction-aware-amr/)

540 completed software simulations, measured controller comparisons, recorded soft real-time tests, ROS/Gazebo evidence, and zero local KiCad ERC/DRC findings. The demo includes interactive measured replays, scenario filters, phase results, project downloads, and a narrated walkthrough.

The project addresses warehouse rover traction on slippery floors. All hardware remains virtual; results reflect modeled behavior and documented industry design intent.
